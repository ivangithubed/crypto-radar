# Крипто-Радар

Показує курси, графіки й список криптовалют із відкритого API (на кшталт CoinGecko). Можна стежити за обраними монетами.

**Для кого:** початківці, які хочуть швидко глянути ціни без реєстрації на біржі.

## Стан

Проєкт ведеться за конвеєром SDD-доставки: стан етапів — у [`.agentic/pipeline-state.md`](.agentic/pipeline-state.md). Стек ще не обрано: його запропонує етап 3 (архітектура).
