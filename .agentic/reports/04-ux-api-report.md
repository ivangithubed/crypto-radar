| Аспект / Рішення | Найпростіший підхід | Галузева Best Practice | Що обрано та чому |
| :--- | :--- | :--- | :--- |
| Стани екрана | Лише стан із даними | Матриця Loading / Empty / Data / Error / Partial / Conflict на кожен екран | **Best Practice:** матриці S-1 – S-5 у розділі 3; 7 джерел помилок продукту замість кодів 4xx/5xx |

| Підказки до термінів | Тултіп лише на hover / `title` | Кнопка «?» → розкривна панель, Esc / × / повторний натиск, не зникає під курсором (WCAG 1.4.13) | **Best Practice:** однаково на телефоні й ПК (AC-7.4) |
