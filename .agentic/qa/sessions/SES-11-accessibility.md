# SES-11: Ручна доступність і адаптивність (NFR-6, NFR-7, WCAG 2.2 AA)

- **Чартер:** Дослідити **усі екрани без миші, на 320 px у мобільній емуляції, у масштабі 200 % і в обох темах пристрою** за допомогою **клавіатури, `getComputedStyle`, `getBoundingClientRect`, axe (`pnpm test:a11y`)**, щоб виявити **пастки фокуса, невидимий фокус, переповнення, малі цілі й низький контраст**.
- **Таймбокс:** 60 хв (план). **Виконавець:** агент; зчитувач, Safari і Firefox — чек-лист власника (TC-087 – TC-090).
- **Коміт:** `040a537`. **Час:** вікно 04:48–04:53 (клавіатура, 320 px, теми); `qa8a-extra.mjs` (640 / 1280) — до 04:58; `pnpm test:a11y` — старт 04:58.

## Нотатки

- **Порядок Tab на `#/` (16 кроків):** «Перейти до вмісту» → «Крипто-Радар» → «Монети» → «Обрані · 3, 3 монети» → поле пошуку → select → «?» Місце / Тікер / Зміна / Капіталізація → Bitcoin → «Прибрати з обраних: Bitcoin» → Tether Gold → «Додати в обрані: Tether Gold» → Ethereum → ★. Логічний, пасток немає.
- **Фокус:** на кожному з 16 елементів `outline: solid` кольору `rgb(185, 168, 238)` з відступом; шапка не липка.
- **Підказка з клавіатури:** Enter відкриває, Esc закриває, фокус на «?».
- **Повідомлення про статус:** «Знайдено N монет», «Упорядковано: …», «Показано 50 з 50», «Solana додано / прибрано з обраних», «Завантажуємо ціни…», «Не вдалося оновити ціни…».
- **Колір:** зміна має знак, стрілку і слово для зчитувача («падіння на 3,9 %»).
- **320×640, мобільна емуляція (Android UA):** `#/`, `#/coin/tether`, `#/coin/bitcoin`, `#/favorites`, `#/abc` — `scrollWidth − clientWidth = 0`, з кожною відкритою підказкою по черзі теж 0; цілей < 24×24 — 0. Скриншот 320 px з відкритою підказкою «Зміна за 7 днів» зроблено.
- **200 % / альбомна:** 640×800, 640×360, 1280×800 на 4 маршрутах — переповнення 0.
- **Теми:** схема пристрою темна → `data-theme="dark"`; світла → `data-theme="light"`, `crypto-radar:theme` не записується. Перемикача теми немає — US-10 у спринті 2.
- **axe:** `pnpm test:a11y` → 40 passed (36 axe: 9 екранів і станів × 2 теми × телефон / ПК, + 4 reflow).
- **Фокус після зміни маршруту:** `BODY` на S-1, S-2, S-3; h1 лише на S-4.
- **Не виконано агентом:** зчитувач (NVDA / VoiceOver), Safari iOS / macOS, Firefox, Edge, голосове керування (2.5.3) — TC-087 – TC-089, виконує власник.
