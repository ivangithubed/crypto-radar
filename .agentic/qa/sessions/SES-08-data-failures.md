# SES-08: Збої джерела, свіжість і ліміт CoinGecko (US-8, NFR-1, NFR-3)

- **Чартер:** Дослідити **стани Loading / Error / «Ціни застаріли» і повтор** за допомогою **живого 429 CoinGecko без CORS, підміни 429 / 500 / обриву / некоректної форми / `null` у полі й годинника сторінки**, щоб виявити **хибні тексти помилок, зайві запити під лімітом і показ застарілих цін**.
- **Таймбокс:** 60 хв (план). **Виконавець:** агент. **Коміт:** `040a537`.
- **Час (з годинника):** `curl` 04:48 → 200 з `access-control-allow-origin: *`; `curl` 04:52:56 → 429, `Retry-After: 36`, без CORS; вивід сторінки 04:53:14 і 04:53:38; `qa8a.mjs` 04:55:30–04:56:33.

## Нотатки

- **Живий 429 без CORS (04:53:14):** `navigator.onLine === true`, блок «Немає з'єднання», 3 запити топ-50 (21 мс, 2054 мс, 6071 мс), `responseStatus = 0`; консоль — 3 × «blocked by CORS policy» для `fetch` і 1 × для preload `link element`. Скриншот — `.agentic/qa/evidence/BUG-001-429-shows-no-connection-320px.jpg`.
- **Повтор під час 429 (04:53:38):** кнопка «Завантажуємо…», `aria-disabled="true"`, скелетона немає; ще 2 запити впали, третій (після відновлення) — 200 → 25 монет, фокус на h1 «Топ-50 монет».
- **Підміна** (8 с після відкриття): 429 з CORS → «Не вдалося отримати ціни», 1 запит; 500 → той самий текст, 3 запити; обрив (`route.abort`) при `onLine=true` → «Немає з'єднання», 3 запити; некоректна форма → «Не вдалося…», 1 запит; у всіх — без цін, без панелі сортування, дисклеймер на місці.
- **Важливо:** «429 без CORS» на підміні Playwright дав «Не вдалося отримати ціни» і 1 запит — `route.fulfill` CORS не блокує, тож фікстури етапів 6–7 цей ризик не ловлять.
- Повтор при постійному 429 → знову Error, статус «Не вдалося оновити ціни. Спробуйте ще раз за хвилину.», фокус на кнопці, 2 запити.
- Межа свіжості (годинник зафіксовано): 299 с і 300 с → ціни; 301 с → «Ціни застаріли», 0 рядків.
- Застарівання на відкритому екрані (давність 60 с, далі 500): +1…+3 хв ціни видно; +4 хв (давність > 300 с) → «Ціни застаріли», цін немає; за 5 хв 13 запитів (1 + 4 цикли × 3 через повтори 5xx — очікувано за P-4).
- Loading (без відповіді): статус «Завантажуємо ціни…», скелетон; `aria-busy="true"` стоїть на обгортці екрана всередині `<main>`, а не на `<main>`, як пише UX §3 (без впливу на користувача).
- `null` у `price_change_percentage_7d_in_currency` однієї монети → увесь список у помилці «Не вдалося отримати ціни».
- Кількість запитів (NFR-3, свіжі дані): на відкритті 1 топ-50 + 1 стейблкоїни; за 5 хв годинника +5 топ-50.

## Знахідки

- **BUG-001** (Major / P1) — 429 без CORS → «Немає з'єднання» і 2 зайві повтори.
- **BUG-003** (Major / P2) — одна монета з `null` кладе весь знімок.
